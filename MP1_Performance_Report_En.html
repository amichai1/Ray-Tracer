Mini-Project 1 – Anti-Aliasing and Depth of Field Performance Measurements

Render-time report for image-quality enhancement features
Amichai Mukades & Michael Dabah  ·  ISE5786  ·  2025–2026

Mini-Project 1 implemented two image-quality enhancement algorithms: Anti-Aliasing (AA) via grid-based Super-Sampling — each pixel is sampled with a 3×3 grid of rays (9 rays per pixel) whose colours are averaged — and Depth of Field (DOF) via aperture simulation — each primary ray is replaced by multiple samples through a circular aperture, creating a realistic focus effect. Both features were measured on the MP1Tests scene.

MP1Tests – individual impact of AA and DOF

Each feature is measured against its own baseline (feature off). Overhead = time with feature ÷ baseline time.

Key observations

  • AA overhead far exceeds the nominal 9× ray count. Each of the 9 super-sampling rays spawns secondary rays for shadows, reflections, and transparency. The cumulative primary and secondary ray count produces an overhead of ~68×, well above the naive 9× expectation.
  • DOF carries a similar overhead to AA (~67×). Each pixel is sampled at multiple aperture points, and each such ray again spawns secondary rays. The cost structure mirrors super-sampling exactly.

Summary: Both MP1 features (AA and DOF) impose heavy overhead (~67–68×), driven by the multiplication of primary and secondary rays per pixel.
